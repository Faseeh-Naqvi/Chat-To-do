Make sure to start building this project in a Virtual Environment
Open a terminal and execute the following commands:

cd _openAI-Integration
python -m venv openAI (only need to set this up once, for god's sake do not commit this to the repository, add /openAI to gitignore if not already present)

IF YOU ARE ON LINUX:
source openai_project/bin/activate

IF YOU ARE ON WINDOWS:
openai_project\Scripts\activate
